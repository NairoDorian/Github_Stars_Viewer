▸ 🔑 GitHub token click to show / hide

Without a token GitHub allows only 60 requests/hour, which isn't enough to index READMEs, commits or releases. With a token you get 5,000/hour.

  1. Open github.com/settings/personal-access-tokens/new (fine-grained) or tokens/new (classic).
  2. Set an expiration and pick the permissions/scopes (see below), then generate the token.
  3. Paste it below and click Save & check. Where it's kept: only in this tab, unless 💾 Keep cache is on; then in data/config.json next to the app when running locally, or in this browser online. Without it the token is forgotten when you close the tab. It's only ever sent to api.github.com.
Which permissions or scopes?
• Browse, search, READMEs, commits, releases, suggestions: no permissions or scopes needed (public repositories only).
• ☆ Star buttons in suggestions (star on GitHub from this page): with a fine-grained token, set Account permissions → Starring: Read and write (no repo write access needed); with a classic token, tick public_repo.
