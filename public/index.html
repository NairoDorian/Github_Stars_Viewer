★ Stars Viewer

This page can't run as a file. Use it online at nairodorian.github.io/Github_Stars_Viewer, or locally: double-click start.bat (or run node server.js) and open http://localhost:8787.
▸ 🔑 GitHub token click to show / hide

Without a token GitHub allows only 60 requests/hour, which isn't enough to index READMEs or fetch releases. With a token you get 5,000/hour.

  1. Open github.com/settings/tokens/new (classic token).
  2. Set an expiration and pick the scopes (see below), then click Generate token.
  3. Paste it below and click Save & check. Where it's kept: running locally, in data/config.json next to the app; online, in this browser only if 💾 Keep cache in this browser is on (otherwise it's forgotten when you close the tab). It's only ever sent to api.github.com.
Which scopes?
• Browse, search, READMEs, releases, suggestions: no scope needed, leave everything unchecked.
• ☆ Star buttons in suggestions (star/unstar on GitHub from this page): tick only public_repo. GitHub has no star-only scope, so public_repo is the smallest that allows starring. It also allows writing to your public repos, but this app only uses it to star and unstar. The check below shows “★ can star” when your token allows it.
